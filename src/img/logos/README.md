# Printer logos

Logos in this folder show up in Settings > Appearance > Printer icon, where each printer can pick one for its browser tab and the top bar.

- Put an `.svg`, `.png` or `.webp` file here. Square or close to square works best, it is shown fitted into a square.
- The file name becomes the name in the list: `rat-rig.svg` shows as "Rat Rig". To use another name, add it to `names.json`: `{ "rat-rig": "Rat Rig" }`.
- Only add logos you are allowed to redistribute. Most printer and brand logos are trademarks, so ask the owner or check their usage terms first.
